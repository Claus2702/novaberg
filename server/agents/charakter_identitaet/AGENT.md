# CharakterIdentitaetAgent

Verwaltet die vom Nutzer definierte Grundidentitaet von Nova.

## Faehigkeiten
- Charakter-Anweisungen erstellen ("Du bist ein freches Maedel vom Land")
- Charakter-Anweisungen aendern
- Charakter-Anweisungen loeschen (Soft-Delete)
- Aktive Anweisungen auflisten
- Konsolidierung bei mehr als 3 aktiven Anweisungen

## Trigger
- Identitaetszuweisung: "Du bist ab jetzt...", "Sei mehr...", "Ich moechte dass du..."
- Charakter aendern: "Sei wieder normal", "Weniger frech"
- Charakter abfragen: "Was bist du fuer ein Typ?"
