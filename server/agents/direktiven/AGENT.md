# DirektivenAgent

Verwaltet absolute Verhaltensanweisungen des Nutzers an Nova.
Direktiven sind Regeln, die Nova befolgen MUSS.

## Faehigkeiten
- Direktiven erstellen ("Sprich nie von Milch!")
- Direktiven aendern
- Direktiven loeschen (Soft-Delete)
- Aktive Direktiven auflisten
- Kontext-Aufloesung bei impliziten Direktiven ("Sag das nie mehr!")

## Trigger
- Imperative mit "nie", "immer", "ab jetzt", "ab sofort"
- Verbote: "nicht mehr", "hoer auf", "lass das"
- Regelaenderung: "Du darfst wieder...", "Das ist nicht mehr noetig"
- Regelabfrage: "Welche Regeln hast du?"
